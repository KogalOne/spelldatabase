# 🎲 DnD.su Spell Ratings Database

Этот репозиторий содержит JSON-базу данных для пользовательского скрипта **[DnD.su Spell Ratings](https://greasyfork.org/ru/scripts/591890-dnd-su-spell-ratings)**. 

Скрипт улучшает интерфейс сайтов **dnd.su** и **5e14.dnd.su**, добавляя удобную, ненавязчивую и умную систему оценок заклинаний (тир-лист) прямо в текст сайта.

---

## 🌟 Возможности скрипта

- 📊 **Компактные индикаторы:** Мини-бейджи с оценками за эффективность в бою и вне боя в общих списках, бестиарии и описаниях классов.
- 📜 **Подробная панель:** Развёрнутые бейджи на странице конкретного заклинания.
- ⚠️ **Система предупреждений:**
  - 🔴 **Ловушки:** Красная обводка для заклинаний, которые неэффективны по RAW.
  - 🟣/🔵 **Материальные компоненты:** Маркеры для заклинаний с ценными или расходуемыми компонентами.
- 💡 **Умные тултипы:** Подробные обоснования оценок с учётом правил (RAW), синергии с чертами и классами. Тултип автоматически подстраивается под границы экрана.
- 🔘 **Переключатель:** Кнопка в шапке сайта для мгновенного скрытия всех дополнений.

## 📥 Установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера.
2. Перейдите на страницу скрипта на GreasyFork и нажмите **«Установить»**: **[Ссылка на GreasyFork](https://greasyfork.org/ru/scripts/591890-dnd-su-spell-ratings)**
3. Перезагрузите страницу dnd.su.

## ️ Структура базы данных (Для разработчиков)

База данных представляет собой JSON-файл, где ключом является ID заклинания с dnd.su.

**Пример структуры:**
```json
{
  "3050": {
    "combat": "S",
    "utility": "F",
    "upcast": "S",
    "trap": false,
    "material": true,
    "hint": [
      "Интеллект — слабое место многих монстров.",
      "Даёт -1к4 к следующему спасброску цели."
    ]
  }
}
